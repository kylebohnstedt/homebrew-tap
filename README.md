# kylebohnstedt/homebrew-tap

Homebrew casks for [ManaMeter](https://manameter.app/), a menu bar meter for AI coding tool
usage limits.

```sh
brew install --cask kylebohnstedt/tap/manameter       # the Mac app
brew install --cask kylebohnstedt/tap/manameter-cli   # the manameter command-line tool
```

The app updates itself with Sparkle, so `brew upgrade` leaves it alone. ManaMeter's release
script generates these casks; don't edit them by hand.
